# `images/` 目录说明

本目录用于集中存放博客的**图片资源**（如文章正文配图、管理员头像等）。

## 工作机制

1. 管理员在网页「管理后台」点击上传图片或上传新头像时，前端会调用 `POST /api/upload`。
2. 后端接口校验图片类型（支持 `png` / `jpg` / `jpeg` / `webp` / `gif` / `svg`，单张不超过 `4MB`）后，自动以 `时间戳-文件名` 命名并提交保存到本目录。
3. 前端通过 `/api/image?path=images/xxx` 访问图片，即使你的 GitHub 仓库设为 **Private（私有）**，访客也能正常加载图片。

## 文件清单

| 文件名 | 作用说明 |
| :--- | :--- |
| `.gitkeep` | 占位文件，用于在尚未上传任何图片时让 Git 保留 `images/` 目录 |
| `*.png / *.jpg / ...` | 后续通过管理后台上传的图片会自动出现在这里 |
