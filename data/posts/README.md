# 文章分类目录说明

本目录用于按板块独立存放博客文章的 Markdown 源文件，方便在 GitHub 仓库中直接按分类检索、备份与查看每篇文章内容。

## 目录结构

除「最新动态」（前台聚合全部板块文章）外，其余 4 个板块均对应独立子目录：

```text
data/posts/
├── 科学网络/      # 科学网络相关文章（*.md）
├── 小众软件/      # 小众软件相关文章（*.md）
├── 网站优选/      # 网站优选相关文章（*.md）
├── 技术手记/      # 技术手记相关文章（*.md）
└── README.md      # 本说明文档
```

## 单篇文章格式

每篇文章以 `<文章ID>.md` 命名，采用 **YAML Frontmatter + Markdown 正文** 格式：

```markdown
---
id: "example-post"
title: "文章标题"
category: "科学网络"
date: "2026-11-15"
readTime: "6 分钟"
featured: false
excerpt: "一句话简介"
---

这里是文章 Markdown 正文内容……
```

## 同步机制说明

1. **后台发布 / 编辑 / 删除**：在博客后台保存文章时，系统会通过 `/api/content` 自动更新汇总索引 `data/posts.json`，并同步创建、更新或清理对应分类文件夹下的 `<id>.md` 文件（若修改了文章所属分类，旧分类文件夹下的文件会自动移除）。
2. **索引与文件关系**：前端首屏加载默认读取 `data/posts.json` 以保证极速渲染；`data/posts/<分类>/<id>.md` 作为面向仓库浏览与归档的独立文章源文件自动保持同步。
