# `data/` 目录说明

本目录用于存放博客的**结构化内容数据**，是 GitHub 作为主要内容存储库的核心目录。

## 文件清单

| 文件名 | 作用说明 | 维护方式 |
| :--- | :--- | :--- |
| `posts.json` | 存放全部博客文章的 ID、标题、分类、发布日期、阅读时长、是否精选、摘要与正文 HTML | 由管理员在网页后台「文章管理」中新建/编辑/删除后，通过 `/api/content` 自动提交更新 |
| `profile.json` | 存放站点名称、副标题、Hero 标语、头像 URL、个人基本信息及联系方式列表 | 由管理员在网页后台「资料设置」中修改后，通过 `/api/content` 自动提交更新 |

## 注意事项

- 请保持两个文件为合法的 **UTF-8 编码 JSON** 格式。
- 页面首次加载时会请求 `/api/content` 从 GitHub 读取本目录下的最新文件，修改提交后无需重新部署即可实时生效。
